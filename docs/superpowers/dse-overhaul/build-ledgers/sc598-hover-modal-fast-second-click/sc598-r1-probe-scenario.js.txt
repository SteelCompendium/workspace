// A DSE modal opened from a hover preview by a REAL press (CDP Input.dispatchMouseEvent), then a SECOND real press `delay` ms after the
// opening click (on the modal title, the Apply input, the backdrop, or the same point with clickCount 2 = a true double-click).
// Trials from SC598_TRIALS="variant:mode:opener:target:delay,...":
//   variant  off | a | a2   (window.__sc598, read by the prototype bundle only; the base bundle ignores it)
//   mode     rv | lp
//   opener   stamtext (press on the bar's "15" text: 150 ms helper) | bar (press on the bar, not on text: 10 ms helper) |
//            kbd (script focus + Enter: SC-597 path) | panetext (the note open in the pane, no preview: control) |
//            initdbl (double-click on the Goblin Captain's grid cell in the tracker preview: opens a stamina modal on dblclick)
//   target   title | input | backdrop | dbl | apply | none
//   delay    ms after the opening click (the second press is sent when the Node-side clock says so; the in-page gap is logged)
