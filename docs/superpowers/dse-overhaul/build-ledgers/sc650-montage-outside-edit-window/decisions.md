## Ticket requirement (verbatim, SC-650 description)

> Open a montage window (Log an action, Add a hero, Set limits, or the edit sheet of a logged action). While it is open, the note changes from outside (another pane, Sync, another app). The window closes with the old card, nothing tells the user why, and keyboard focus ends on the page.
>
> Nothing is lost: the outside edit survives and the window saves nothing. The user just loses what they were typing in the window and has to tab back from the top of the note.
>
> Expected: the same handling initiative got in SC-608, at least focus handed back to the rebuilt card's control that opened the window.
