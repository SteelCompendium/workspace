> Found while fixing SC-466 (ds-stamina-bar). Not yet confirmed for other blocks.
>
> **Suspected repro:** a persisted block built on `ComponentWrapper` (for example `ds-skills`, which also carries `collapse_default`), with only its content keys written. Make any change that writes the block back. The written block may now also contain `collapsible` / `collapse_default` (and any other parser-filled defaults) that the user never wrote.
>
> **Expected:** same contract SC-466 set for the stamina bar. A key that was absent from the source and still equals its default stays absent. Every authored key is still written.
>
> **Starting point:** SC-466's fix in `src/elements/stamina-bar/model.ts` (a per-instance record of which default keys the source omitted, used by `serialize()`). Check whether it should become a shared helper.
