## 3. Footgun (one line)

- `RECOV-R07` (stamina-bar Recoveries popover: `w.count` 1 vs 2) is load-sensitive: its +/- clicks and Catch breath can straddle the 400 ms debounce when the host is at loadavg 20+. It is not a regression signal; re-run alone and on a clean base before blaming a change.
