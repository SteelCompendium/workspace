**Camera additions** (all inside the `--docs` path — the sweep, specials, and the
shots/freeze/parity gates are untouched, as the unchanged 200/66 confirm):

- **kinds `palette` and `search`** — open the real command, then type into it the way a user
  does (set the input value, dispatch a real `input` event so Obsidian's own suggester
  runs). Both open a note first: `search` is an `editorCallback` command that won't run
  without an editor, and the palette *hides every editor command* — i.e. all the Insert
  ones — when the active leaf isn't a note. That second one cost a wasted capture before I
  spotted it.
- **`mode: 'source'` + `frame: 'leaf'`** on note captures. Source-mode has no element root,
  so it's always leaf-framed; `frame: 'leaf'` also gives the tutorial framing for rendered
  notes (tab, breadcrumb, pane), which is the whole point of a "switch to Reading view"
  screenshot.
- **`pref` on note captures**, with an explicit `prefRestore` (printPreview is an
  `'on'`/`'off'` string; `!value` would have written `false`, a value the catalog never
  defines).
- **`DOCS_COMPENDIUM_SEED`** — the compendium entries the docs captures reference, copied
  from `test/fixtures/md-dse` into the git-ignored demo vault. `notes-gen` seeds three files
  for the ground-truth captures; a tutorial needs a monster the search modal can *find* and
  a reference block can *resolve*.

### A race worth naming (found and fixed here)

Obsidian fires `layoutReady` **before** it has read the frontmatter of files copied in just
before launch. A reference block rendered in that window resolves the file but gets no
`type`, so the card degrades to *"found but not renderable … (type: unknown) … re-sync"* —
and the capture's own wait **passes**, because the element root does appear; it's just an
error card. The first run of these captures published a screenshot telling beginners the
product was broken. Docs mode now waits for the metadata cache to have indexed the seeded
files before any capture. Silent, intermittent, and exactly the class of thing that makes
generated screenshots worth having: it was caught by looking at the picture.
