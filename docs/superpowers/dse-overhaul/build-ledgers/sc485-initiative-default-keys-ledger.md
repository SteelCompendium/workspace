## Spec (ticket description, verbatim, 2026-10-22)

> Found by the SC-482 survey. Left out of SC-482 because it needs its own design.
>
> **Repro (measured):** a `ds-initiative` block with one hero (`Ash`, `max_stamina: 20`) and one group (`Goblins`, one creature with `max_stamina: 10`, `amount: 2`). Toggle the hero's turn. The written block now also has, per hero: `conditions: []`, `isHero: true`, `current_stamina: 20`, `temp_stamina: 0`; per creature: `isHero: false` and an `instances:` list of 2 entries each with `id`, `current_stamina`, `temp_stamina`, `conditions: []`; per group: `has_taken_turn: false`, `is_squad: false`; and at the top `malice: {value: 0}`.
>
> **Expected:** the SC-466 / SC-482 contract. A key absent from the source that still equals its default stays absent. Every authored key is still written.
>
> **Why it is separate:** the defaults are nested inside user-authored arrays, `resolveRefs` fills stamina from statblocks after parse, `isHero` is written even on fully-authored blocks, and `test/unit/model/initiative-serialize.test.ts` pins byte equality to the legacy writer. SC-482's shared helper (`src/elements/shared/undeclaredDefaults.ts`) is the starting point.
